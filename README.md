# Система Проката Оборудования

Desktop приложение на C# Windows Forms + SQLite
код проекта находится в Branch (Master)

## Возможности

- ✅ Управление оборудованием (CRUD)
- ✅ Управление клиентами
- ✅ Управление договорами проката
- ✅ Управление пользователями
- ✅ Отчёты
- ✅ Авторизация

## Технологии

- C# + Windows Forms
- SQLite (Microsoft.Data.Sqlite)
- Layered Architecture (Models, Services, Data)

## Как запустить

1. Открой файл `EquipmentRentalSystem.sln`
2. Нажми `F5` (Start Debugging)
3. Логин: `admin`
4. Пароль: `admin123`
